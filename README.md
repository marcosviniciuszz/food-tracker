# Food Tracker

I created this project to strengthen my knowledge in Go and used MongoDB for data persistence. The API monitors new orders made on iFood, so when it detects a new order, it inserts it into MongoDB.

The user can then confirm the order, mark it as in preparation, and later mark it as ready. (All updates happen in real-time with iFood and notify the customer)
